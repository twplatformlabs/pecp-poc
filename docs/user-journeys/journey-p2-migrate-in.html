Open questions — mostly unscoped

Q1
Capability scope. Which capabilities are in scope first — repos, k8s manifests, secrets — and each one's migration approach? Some workloads, not all.
Q2
Self-service tool. What the consumer-run tool actually looks like (CLI subcommands? a wizard?) and how it's invoked per capability.
Q3
Build vs buy. Per capability — a manifest translator (custom) vs state tools (e.g. Velero) vs off-the-shelf. Needs a landscape review.
Q4
Cutover & verification. How traffic cutover and rollback-on-failure are handled; how the team validates parity.
Q5
Source coverage. Other k8s first — when do non-k8s sources ("somewhere else") come in, and in which phase?
Q6
Phasing. Which capabilities are Phase 2 vs Phase 3 vs Phase 4+ — this flow spans several.
